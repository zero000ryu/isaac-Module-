# 平面設計大師 · Floor Plan Studio

在瀏覽器裡畫室內平面圖、出工程圖、看 3D 效果圖的單檔網站。用瀏覽器打開 `index.html` 就能用，不需要安裝。

## 線上使用
- **GitHub Pages**：把這個分支合併到 `main`，再到 GitHub 的 **Settings → Pages → Source** 選 **GitHub Actions**，網站就會自動發布到 `https://zero000ryu.github.io/isaac-Module-/`。私人 repo 要有 GitHub Pro 或團隊方案才能使用 Pages；不然就把 repo 改成公開。
- **其他免費空間**：`index.html` 是單一檔案，直接上傳到 Netlify Drop、Cloudflare Pages 或 Vercel 也可以使用。

## 功能
**描圖與丈量**
- 上傳建商平面圖或手繪照片當底圖，也可以直接把圖片拖到畫布上
- 兩點校正：在圖上點兩個已知距離的點並輸入實際尺寸，可以只縮放底圖，也可以連同已畫的圖一起縮放
- 丈量工具、尺寸線，以及依牆中心線自動標註外圍尺寸

**繪圖**
- 畫牆時端點自動吸附，接近 45° 會自動對齊；房間會即時算出 m² 和坪數
- 隔間材料：RC 牆、紅磚牆、輕質白磚、木作隔間、輕鋼架、玻璃隔間，各有不同的剖面填充圖樣
- 房間可以設定地坪（超耐磨、實木、人字拼、石英磚、大理石、板岩、止滑磚、磐多魔、水泥粉光等）、天花（平釘、造型間接燈槽、明架、鋁條、木格柵）、天花高、牆面材料與防水範圍
- 水電管線：冷水、熱水、排水、瓦斯、電線管、弱電管、冷媒管、冷凝排水、新風與排風管，每種都可以選管徑

**材料庫（約 80 項，規格都可選擇或調整）**
- 家具、電器、系統櫃（板材、門片、櫃高，並換算台尺）、衛浴（品牌、管距、免治、淋浴拉門）
- 燈具：崁燈開孔、色溫、瓦數、調光
- 插座、開關、電話孔、網路孔、電視孔、配電箱、弱電箱，可設定離地高度與迴路
- 冷氣：壁掛、吊隱、嵌入、室外機，可選品牌、型號、能力與機型，並依房間坪數給建議能力；全熱交換器可選風量 CMH，另有出風口、回風口與暖風機

**出圖**
- A3 工程圖共五張：A-01 平面配置、A-02 隔間及地坪、A-03 天花燈具、A-04 水電插座、A-05 空調全熱
- 每張圖都附圖框、圖例、附註、比例尺、指北針與圖號，可輸出 PNG 或 SVG
- 材料數量表會統計地坪、天花、隔間、牆面、系統櫃、設備數量和管線長度，可以複製貼到 Excel

**3D 效果圖**
- 提供歐風古典、工業風、現代簡約三種風格，可切換斜角、鳥瞰和人視角
- 可以調整牆高剖切，並擷取效果圖

## 注意
- 冷氣與全熱交換器的尺寸、能力建議只是參考，實際請以原廠型錄與技師評估為準
- 管線路徑僅為示意
- 資料存在瀏覽器裡，換電腦時請先用「出圖 → JSON」備份
