# 平面設計大師 · Floor Plan Studio

在瀏覽器裡畫室內平面圖、出工程圖、看 3D 效果圖的單檔網站。用瀏覽器打開 `index.html` 就能用，不需要安裝。

## 線上使用
- **牙醫資料庫**：**https://dental.top-geng.com/**，登入後才能使用（和牙材 ERP 同一套系統、同一組帳號，網域掛在 Vercel 的 ERP 專案）。GitHub Pages 只部署一個轉址頁，導到這個網址。
- **其他免費空間**：`index.html` 是單一檔案，直接上傳到 Netlify Drop、Cloudflare Pages 或 Vercel 也可以使用。

## 功能
**專案管理**
- 可以開好幾個專案（例如不同房子或不同業主），隨時新增、切換、重新命名、複製、刪除
- 每個專案自動存在瀏覽器裡（IndexedDB），重新整理後也不會遺失
- 「專案 → 範本圖面」可以直接開啟 `plans/` 裡的圖面（辦公室實測版、辦公室改造版）

**匯入圖檔、描圖與丈量**
- 上方「匯入圖檔」按鈕可以匯入 JPG、PNG、PDF（建商平面圖、權狀附圖、手繪照片），也可以拖到畫布上，或複製後按 Ctrl+V 貼上
- 底圖可以調整透明度、位置，也能旋轉 90° 或換一張
- 兩點校正：在圖上點兩個已知距離的點並輸入實際尺寸，可以只縮放底圖，也可以連同已畫的圖一起縮放
- 丈量工具、尺寸線，以及依牆中心線自動標註外圍尺寸

**繪圖**
- 畫牆時端點自動吸附，接近 45° 會自動對齊；房間會即時算出 m² 和坪數
- 隔間材料：RC 牆、紅磚牆、輕質白磚、木作隔間、輕鋼架、玻璃隔間，各有不同的剖面填充圖樣
- 房間可以設定地坪（超耐磨、實木、人字拼、石英磚、大理石、板岩、止滑磚、磐多魔、水泥粉光等）、天花（平釘、造型間接燈槽、明架、鋁條、木格柵）、天花高、牆面材料與防水範圍
- 水電管線：冷水、熱水、排水、瓦斯、電線管、弱電管、冷媒管、冷凝排水、新風與排風管，每種都可以選管徑

**材料庫（約 80 項，規格都可選擇或調整）**
- 家具、電器、系統櫃（板材、門片、櫃高，並換算台尺）、衛浴（品牌、管距、免治、淋浴拉門）
- 燈具：崁燈開孔、色溫、瓦數、調光
- 插座、開關、電話孔、網路孔、電視孔、配電箱、弱電箱，可設定離地高度與迴路
- 冷氣：壁掛、吊隱、嵌入、室外機，可選品牌、型號、能力與機型，並依房間坪數給建議能力；全熱交換器可選風量 CMH，另有出風口、回風口與暖風機

**出圖**
- A3 工程圖共五張：A-01 平面配置、A-02 隔間及地坪、A-03 天花燈具、A-04 水電插座、A-05 空調全熱
- 每張圖都附圖框、圖例、附註、比例尺、指北針與圖號，可輸出 PNG 或 SVG
- 材料數量表會統計地坪、天花、隔間、牆面、系統櫃、設備數量和管線長度，可以複製貼到 Excel

**3D 效果圖**
- 提供歐風古典、工業風、現代簡約三種風格，可切換斜角、鳥瞰和人視角
- 可以調整牆高剖切，並擷取效果圖

## 診所名單系統（`clinics.html`）
從上方「診所名單」按鈕進入，或直接打開 `clinics.html`（`https://dental.top-geng.com/dental/clinics.html`）。
- 新增、編輯、刪除診所：名稱、科別（可複選）、縣市／區、地址、電話、負責醫師、聯絡人、Email、醫事機構代碼、健保特約、門診時間、標籤、備註
- 狀態分為潛在客戶、洽談中、合作中、暫停，可記錄上次聯絡與下次追蹤日期；逾期或 7 天內要追蹤的會標色提醒
- 關鍵字搜尋（電話可只打部分數字），依縣市、科別、狀態篩選，點欄位標題排序；新增時會提醒可能重複的診所
- 匯入 Excel 另存的 CSV（UTF-8 或 Big5，欄位名稱自動對應，日期接受民國年）；合併模式只會更新檔案裡有填的欄位
- 匯出 CSV、複製貼到 Excel、JSON 備份、列印
- 資料存在這台裝置的瀏覽器裡（IndexedDB），換電腦前請先匯出 JSON 備份

## 美股篩選（`stocks.html`）
從首頁「美股篩選」按鈕進入，或直接打開 `stocks.html`。篩選 S&P 500、Nasdaq-100 成分股和約 60 檔常見 ETF。
- **選股策略**（一鍵套用，之後可以再自己調整條件）：價值股（本益比 ≤18、股價淨值比 ≤3、負債權益比 ≤1.5）、高股息（殖利率 ≥3%、配息率 ≤80%）、成長股（營收、盈餘年增 ≥15%）、合理價成長（PEG ≤1.5）、品質股（ROE、淨利率 ≥15%、負債權益比 ≤1）、ETF 低成本（內扣 ≤0.2%）、ETF 高股息，以及「我的追蹤」
- **自訂條件**：約 30 項指標都可以設最小值／最大值，例如本益比、預估本益比、PEG、股價淨值比、自由現金流殖利率、殖利率、配息率、營收與盈餘成長、ROE、毛利率、負債權益比、Beta、1 個月到 5 年報酬、年化波動、最大回檔、分析師目標價空間、ETF 內扣費用；也可以依產業、指數成分、關鍵字篩選
- **評分**：每檔個股算出價值分、股息分、成長分、品質分（0–100，在全部個股中的百分位）；虧損公司的本益比算最差而不是最便宜
- **欄位組合**：概覽、估值、股息、成長、品質、報酬、ETF；點欄位標題排序，點股票看完整數據與 Yahoo Finance、SEC 年報、Finviz、TradingView 連結
- 星號加入追蹤清單；目前結果可匯出 CSV（Excel 可直接開）；也可以匯入自己的 CSV（Finviz 匯出檔或含 Ticker／Symbol／代號欄的檔案）或 JSON
- **資料更新**：`.github/workflows/update-stocks.yml` 在每個美股交易日收盤後（台灣時間早上 06:41）執行 `scripts/build_stocks.py`，用 yfinance 從 Yahoo Finance 抓基本面與選擇權隱含波動率，並用含息調整後的股價計算報酬，寫入 `data/stocks.json`。某檔抓不到時保留前一天的數字；超過一半抓不到就不更新。要多追蹤其他股票（例如 TSM、ASML），把代號加到 `data/stocks-extra.txt`。第一次使用請到 GitHub → Actions →「Update US stock screener data」→ Run workflow 先產生資料
- **選擇權策略評估**（上方切到「選擇權策略」，或在股票詳細資料按「選擇權策略評估」；網址 `stocks.html#options=AAPL` 可直接開某檔）：
  - 15 種策略一次比較：備兌買權、現金擔保賣權、保護性賣權、領口、買進買權／賣權、多頭買權價差、空頭賣權價差、多頭賣權價差與空頭買權價差（收權利金）、鐵兀鷹、蝶式、買進跨式、買進勒式、賣出勒式；可依看法（看漲、看跌、盤整、大波動）篩選
  - 每種策略算出建立成本、最大獲利／虧損、損益兩平、獲利機率、期望值、年化期望報酬，以及 Delta、Gamma、Theta、Vega
  - 履約價依波動自動挑選（約 ±0.5、±1 個標準差），權利金以 Black-Scholes 算理論價；每一腳的類型、買賣、口數、履約價、權利金都能改，可以填券商報價或自己組合策略
  - 損益圖顯示到期與今天的損益、±1 標準差區間，滑鼠移上去看任一股價的損益
  - 「你預期的波動」預設為過去一年實際波動，和隱含波動率（IV）比較：IV 偏高時賣方策略期望值較好，偏低時買方較好；篩選頁另有「選擇權：賣方」「選擇權：買方」兩個策略，依 IV／實際波動比排序
  - IV 取自 Yahoo 最近 30 天左右到期的價平選擇權（`iv`、`ivDte`）；沒有資料時用實際波動代替
  - 理論價是歐式模型，美股個股選擇權是美式，實際報價會不同；賣出選擇權的損失可能遠大於收到的權利金
- 本工具僅供研究與學習，不構成投資建議；Yahoo Finance 資料可能延遲或有誤，使用前也請自行確認 Yahoo 的使用條款

## 出貨應收彙整（`shipping.html`）
上傳 Word（.docx）、Excel（.xlsx、.xls）、CSV 出貨單，依客戶與帳款月份整理成應收帳款 Excel。檔案只在瀏覽器裡處理，不會上傳。
- 自動讀出客戶、出貨日期、單號和品項（品名、規格、數量、單位、單價、金額），一個檔案裡有多張出貨單也可以；讀不到或合計對不起來的會標「需確認」，可以直接在表格修改
- 品項金額和「數量×單價」相差超過 1 元會標紅並提示正確金額，可一鍵改正；下載的「出貨明細」有「檢查」欄
- 同一客戶的出貨單依日期排序，再依帳款月份分成「XX牙醫-X月份應收款」；可設定每月結帳日（例如 25 日）和是否外加 5% 營業稅
- 「客戶名稱整理」可以把同一家診所的不同寫法合併
- 下載一個彙整 Excel（應收總表、出貨明細、每張應收單各一個工作表），或每張應收單各一個檔案（ZIP）
- 放在牙材 ERP 裡（`scripts/build_erp_shipping.py` 產生 dental-erp 的 `tools/shipping.html`）時多一個「匯入 ERP」步驟，把出貨單建成 ERP 的已出貨訂單

## 全台牙醫診所資料庫（`dental.html`）
網址：**https://dental.top-geng.com/**（登入後使用；每日排程以 `scripts/upload_erp_data.py` 和 secret `DENTAL_DATA_TOKEN` 把資料送進 ERP）

**儀表板**：營業中、健保特約、自費診所數，執業牙醫師人數；各縣市長條圖（點一下就篩選），以及各鄉鎮市區排名。
**搜尋**：名稱、地址、電話、機構代碼、負責人、LINE；可依縣市／區、狀態、有網站／LINE／Google 評分／統編、晚上或週末看診篩選，依 Google 評分、評論數、牙醫師人數排序。點診所可看詳細資料與看診時段，並可「加入我的診所名單」。

**資料來源與更新**（`.github/workflows/update-dental.yml`，每天台灣時間 03:23 自動執行，有變動才更新網站）
| 欄位 | 來源 | 涵蓋率 |
|---|---|---|
| 名稱、地址、電話、看診時段、健保合約 | 健保署 健保特約醫事機構-診所（data.gov.tw/dataset/39283） | 全部健保特約牙醫 |
| 自費診所、鄉鎮市區、牙醫師人數 | 衛福部 醫療機構與人員基本資料（data.gov.tw/dataset/15393） | 全部立案診所 |
| 統一編號 | 財政部 全國營業(稅籍)登記（每週一比對） | 很低：醫療業免營業稅，多數診所沒有稅籍登記 |
| Google 評分、評論數、網站 | Google Places API（`scripts/enrich_google.py`） | 需設定金鑰，見下方 |
| LINE、Facebook、Email、負責人、統編 | 診所官網公開資訊（`scripts/enrich_web.py`，遵守 robots.txt） | 有網站的診所才有 |
| 看診牙醫姓名 | 健保署院所查詢公開的計畫醫師名單（牙周病統合治療、身心障礙服務、牙齒外傷急症）與醫療團名單（`scripts/fetch_dentists.py`，每天更新約 800 筆、約 10 天輪完） | 參加這些計畫的醫師；其他醫師沒有公開名單 |
| 參與健保計畫、掛號費、無障礙、預防保健、健保署目前登記的電話與地址 | 健保署院所查詢詳細頁（`scripts/fetch_nhi_detail.py`，每天約 800 間） | 全部健保特約診所 |
| 醫院牙科（醫學中心、區域、地區醫院） | 健保署健保特約醫院名冊中設有牙科者；醫師姓名同樣取自健保署計畫醫師名單 | 190 家 |
| 院長（負責醫師） | 臺北市牙醫師公會診所查詢（姓名遮蔽一字），與該診所的健保醫師名單比對還原（`scripts/fetch_tda.py`，每月） | 臺北市 |
| 郵遞區號、縣市／鄉鎮市區類型、村里 | 中華郵政郵遞區號前 3 碼與村里名稱表（`data/zip3.json`、`data/villages.json`）；村里取自地址並比對村里名稱表 | 郵遞區號全部；村里限地址有載明者 |
| 任何欄位的人工修正 | `data/dental-extra.csv`（以醫事機構代碼對應，優先採用） | — |

**資料整併與比對**（`build_dental.py` 的 `reconcile`）：每次更新都把各來源交叉比對後合併成一筆。優先順序是人工修正 → 健保署院所查詢（最即時）→ 健保署開放資料 → 衛福部名冊 → 診所官網 → Google。
- 電話：三個來源比對（容許區碼、少一碼的舊號碼），不同的市話標「電話不一致」並保留為其他電話；手機視為額外聯絡方式
- 名稱、地址：比對健保署與衛福部（地址統一中文數字、全半形、里鄰、之／-、多門牌），不同就標記並保留其他名稱／地址
- 醫師：合併各計畫名單去除重複，並與衛福部登記牙醫師人數比較，算出名單涵蓋率
- 同址不同機構代碼：已終止的標記被哪個新機構接手（遷址或改設），營業中的標記同址機構
- 看診時段：健保署（院所查詢即時頁優先，含診所登記的確切時刻）與 Google 地圖營業時間比對，換算成上午／下午／晚上逐格比較，確切時刻相差超過 30 分鐘也會標記「看診時段與 Google 不一致」（需設定 Google API 金鑰）
- 每間診所算出資料完整度；整體統計在 `data/quality.json`，網頁有「資料完整度與比對」卡片與「需查證」篩選

**啟用 Google 評分**：到 Google Cloud 啟用「Places API (New)」並建立 API 金鑰，再到 GitHub repo 的 Settings → Secrets and variables → Actions 新增 `GOOGLE_MAPS_API_KEY`。每天預設查 30 間（約每月 900 次，在 Google 每月免費額度內），可用 repo 變數 `GOOGLE_LIMIT` 調高以加快輪完全部診所。Places API 會依用量計費，請先在 Google Cloud 設好預算上限；Google 的條款限制評分等內容的長期快取，使用前請自行確認。

**ERP 串接（牙材 ERP，erp.top-geng.com）**：每天更新後由 `scripts/sync_erp.py` 自動登入 ERP，把營業中的牙醫診所匯入「客戶／診所名單」（類別：診所）。使用 ERP 自己的批次匯入，名稱已存在的會略過，所以第一次匯入全部、之後只會新增新開業的診所，不會覆蓋在 ERP 修改過的資料。同名診所會在名稱後加上（縣市區）；備註會寫入醫事機構代碼、健保狀態、牙醫師人數、LINE、Google 評分。
  - 啟用方式：GitHub repo → Settings → Secrets and variables → Actions，新增 `ERP_EMAIL`、`ERP_PASSWORD`（需要有客戶名單寫入權限的 ERP 帳號，建議另開一個專用帳號）。
  - 範圍：repo 變數 `ERP_SCOPE`，預設 `open`（全部營業中）；可設 `nhi`（只有健保特約）或縣市清單如 `臺北市,新北市`。
  - 另外也有固定網址 `data/dental.csv`、`data/dental.json` 可供其他系統匯入。

**未收錄的來源**：醫院網站上的醫師職稱、專長、學歷、經歷：台灣醫院網站依「醫療機構網際網路資訊管理辦法」聲明禁止轉錄內容供人點閱，因此不抓取。齒顎矯正、補綴學會專科名單：網站 TLS 憑證與網域不符，無法安全連線；牙周病醫學會網站封鎖程式存取。衛福部醫事查詢系統拒絕程式連線。各縣市牙醫師公會中只有臺北市、新竹市公開診所名單，且負責醫師姓名遮蔽或未列出，資料也已涵蓋在健保署與衛福部名單內；Google 地圖網頁不允許爬取，只能透過官方 API。
