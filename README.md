# 平面設計大師 · Floor Plan Studio

在瀏覽器裡畫室內平面圖的單檔工具。直接用瀏覽器打開 `index.html` 就能用，不需要安裝。

## 功能
- **畫牆**：連續點擊畫牆，端點會自動吸附，接近 45° 時自動對齊，畫線時即時顯示長度
- **房間**：拖曳畫出房間，會自動產生四面牆，並即時算出 m² 和坪數；也可以輸入寬深直接新增房間
- **家具庫**：提供門窗、客廳、臥室、餐廚、衛浴和結構物件，共 30 種，可依名稱搜尋；門窗靠近牆時會自動貼齊並轉向
- **編輯**：移動、等比縮放、旋轉（每 15° 吸附）、複製、調整上下層、換顏色，並可輸入精確尺寸
- **描圖底圖**：上傳建商平面圖或照片，設定實際寬度後就能照著描
- **標註**：尺寸線、文字標註、牆長顯示
- **面積統計**：列出每個房間和全室合計的 m² 與坪
- **匯出／匯入**：PNG、SVG（附圖框、日期與總坪數）和 JSON；支援復原與重做，並自動存到瀏覽器
- **操作**：桌機可用滑鼠滾輪縮放、空白鍵拖曳平移；手機可用雙指縮放

## 快捷鍵
`V` 選取 · `W` 畫牆 · `M` 房間 · `D` 尺寸 · `T` 文字 · `G` 吸附 · `F` 全圖 · `R` 旋轉 90° · `Del` 刪除 · `Ctrl+D` 複製 · `Ctrl+Z / Ctrl+Shift+Z` 復原／重做 · 方向鍵微調

功能設計參考了 Sweet Home 3D、RoomSketcher、Planner 5D、PlanSnapper 與 IKEA 規劃工具。
