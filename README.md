# 平面設計大師 · Floor Plan Studio

在瀏覽器裡畫室內平面圖、出工程圖、看 3D 效果圖的單檔網站。用瀏覽器打開 `index.html` 就能用，不需要安裝。

## 線上使用
- **GitHub Pages**：把這個分支合併到 `main`，再到 GitHub 的 **Settings → Pages → Source** 選 **GitHub Actions**，網站就會自動發布到 `https://zero000ryu.github.io/isaac-Module-/`。私人 repo 要有 GitHub Pro 或團隊方案才能使用 Pages；不然就把 repo 改成公開。
- **其他免費空間**：`index.html` 是單一檔案，直接上傳到 Netlify Drop、Cloudflare Pages 或 Vercel 也可以使用。

## 功能
**專案管理**
- 可以開好幾個專案（例如不同房子或不同業主），隨時新增、切換、重新命名、複製、刪除
- 每個專案自動存在瀏覽器裡（IndexedDB），重新整理後也不會遺失
- 「專案 → 範本圖面」可以直接開啟 `plans/` 裡的圖面（辦公室實測版、辦公室改造版）

**匯入圖檔、描圖與丈量**
- 上方「匯入圖檔」按鈕可以匯入 JPG、PNG、PDF（建商平面圖、權狀附圖、手繪照片），也可以拖到畫布上，或複製後按 Ctrl+V 貼上
- 底圖可以調整透明度、位置，也能旋轉 90° 或換一張
- 兩點校正：在圖上點兩個已知距離的點並輸入實際尺寸，可以只縮放底圖，也可以連同已畫的圖一起縮放
- 丈量工具、尺寸線，以及依牆中心線自動標註外圍尺寸

**繪圖**
- 畫牆時端點自動吸附，接近 45° 會自動對齊；房間會即時算出 m² 和坪數
- 隔間材料：RC 牆、紅磚牆、輕質白磚、木作隔間、輕鋼架、玻璃隔間，各有不同的剖面填充圖樣
- 房間可以設定地坪（超耐磨、實木、人字拼、石英磚、大理石、板岩、止滑磚、磐多魔、水泥粉光等）、天花（平釘、造型間接燈槽、明架、鋁條、木格柵）、天花高、牆面材料與防水範圍
- 水電管線：冷水、熱水、排水、瓦斯、電線管、弱電管、冷媒管、冷凝排水、新風與排風管，每種都可以選管徑

**材料庫（約 80 項，規格都可選擇或調整）**
- 家具、電器、系統櫃（板材、門片、櫃高，並換算台尺）、衛浴（品牌、管距、免治、淋浴拉門）
- 燈具：崁燈開孔、色溫、瓦數、調光
- 插座、開關、電話孔、網路孔、電視孔、配電箱、弱電箱，可設定離地高度與迴路
- 冷氣：壁掛、吊隱、嵌入、室外機，可選品牌、型號、能力與機型，並依房間坪數給建議能力；全熱交換器可選風量 CMH，另有出風口、回風口與暖風機

**出圖**
- A3 工程圖共五張：A-01 平面配置、A-02 隔間及地坪、A-03 天花燈具、A-04 水電插座、A-05 空調全熱
- 每張圖都附圖框、圖例、附註、比例尺、指北針與圖號，可輸出 PNG 或 SVG
- 材料數量表會統計地坪、天花、隔間、牆面、系統櫃、設備數量和管線長度，可以複製貼到 Excel

**3D 效果圖**
- 提供歐風古典、工業風、現代簡約三種風格，可切換斜角、鳥瞰和人視角
- 可以調整牆高剖切，並擷取效果圖

## 診所名單系統（`clinics.html`）
從上方「診所名單」按鈕進入，或直接打開 `clinics.html`（網址：`https://zero000ryu.github.io/isaac-Module-/clinics.html`）。
- 新增、編輯、刪除診所：名稱、科別（可複選）、縣市／區、地址、電話、負責醫師、聯絡人、Email、醫事機構代碼、健保特約、門診時間、標籤、備註
- 狀態分為潛在客戶、洽談中、合作中、暫停，可記錄上次聯絡與下次追蹤日期；逾期或 7 天內要追蹤的會標色提醒
- 關鍵字搜尋（電話可只打部分數字），依縣市、科別、狀態篩選，點欄位標題排序；新增時會提醒可能重複的診所
- 匯入 Excel 另存的 CSV（UTF-8 或 Big5，欄位名稱自動對應，日期接受民國年）；合併模式只會更新檔案裡有填的欄位
- 匯出 CSV、複製貼到 Excel、JSON 備份、列印
- 資料存在這台裝置的瀏覽器裡（IndexedDB），換電腦前請先匯出 JSON 備份

## 全台牙醫診所資料庫（`dental.html`）
網址：`https://zero000ryu.github.io/isaac-Module-/dental.html`

**儀表板**：營業中、健保特約、自費診所數，執業牙醫師人數；各縣市長條圖（點一下就篩選），以及各鄉鎮市區排名。
**搜尋**：名稱、地址、電話、機構代碼、負責人、LINE；可依縣市／區、狀態、有網站／LINE／Google 評分／統編、晚上或週末看診篩選，依 Google 評分、評論數、牙醫師人數排序。點診所可看詳細資料與看診時段，並可「加入我的診所名單」。

**資料來源與更新**（`.github/workflows/update-dental.yml`，每天台灣時間 03:23 自動執行，有變動才更新網站）
| 欄位 | 來源 | 涵蓋率 |
|---|---|---|
| 名稱、地址、電話、看診時段、健保合約 | 健保署 健保特約醫事機構-診所（data.gov.tw/dataset/39283） | 全部健保特約牙醫 |
| 自費診所、鄉鎮市區、牙醫師人數 | 衛福部 醫療機構與人員基本資料（data.gov.tw/dataset/15393） | 全部立案診所 |
| 統一編號 | 財政部 全國營業(稅籍)登記（每週一比對） | 很低：醫療業免營業稅，多數診所沒有稅籍登記 |
| Google 評分、評論數、網站 | Google Places API（`scripts/enrich_google.py`） | 需設定金鑰，見下方 |
| LINE、Facebook、Email、負責人、統編 | 診所官網公開資訊（`scripts/enrich_web.py`，遵守 robots.txt） | 有網站的診所才有 |
| 任何欄位的人工修正 | `data/dental-extra.csv`（以醫事機構代碼對應，優先採用） | — |

**啟用 Google 評分**：到 Google Cloud 啟用「Places API (New)」並建立 API 金鑰，再到 GitHub repo 的 Settings → Secrets and variables → Actions 新增 `GOOGLE_MAPS_API_KEY`。每天預設查 30 間（約每月 900 次，在 Google 每月免費額度內），可用 repo 變數 `GOOGLE_LIMIT` 調高以加快輪完全部診所。Places API 會依用量計費，請先在 Google Cloud 設好預算上限；Google 的條款限制評分等內容的長期快取，使用前請自行確認。

**ERP 串接（牙材 ERP，erp.top-geng.com）**：每天更新後由 `scripts/sync_erp.py` 自動登入 ERP，把營業中的牙醫診所匯入「客戶／診所名單」（類別：診所）。使用 ERP 自己的批次匯入，名稱已存在的會略過，所以第一次匯入全部、之後只會新增新開業的診所，不會覆蓋在 ERP 修改過的資料。同名診所會在名稱後加上（縣市區）；備註會寫入醫事機構代碼、健保狀態、牙醫師人數、LINE、Google 評分。
  - 啟用方式：GitHub repo → Settings → Secrets and variables → Actions，新增 `ERP_EMAIL`、`ERP_PASSWORD`（需要有客戶名單寫入權限的 ERP 帳號，建議另開一個專用帳號）。
  - 範圍：repo 變數 `ERP_SCOPE`，預設 `open`（全部營業中）；可設 `nhi`（只有健保特約）或縣市清單如 `臺北市,新北市`。
  - 另外也有固定網址 `data/dental.csv`、`data/dental.json` 可供其他系統匯入。

**未收錄的來源**：牙醫師公會、牙醫師學會沒有公開的批次名冊；Google 地圖網頁不允許爬取，只能透過官方 API。
